# D0-A2 — 浮空道具验收

开发和画面对照基准为最新 `origin/dev@c7f99e1320ced64761efbd36da7a44a9af4f8554`，包含指定基准 `7861c737`。规则见[冻结契约](../contracts/D0-A2-floating-pickups.md)。本阶段仅修改 ELSEWHERE 的道具玩法，保留 BSD-3-Clause。

ELSEWHERE 在 BREAK 的第 306.66 拍（开局后约 2:24）提供一次拾取机会。它距前一道 Diamond 约 1.252 秒，距下一道 Iris 约 1.247 秒，且不计入门谱。道具中心固定在局部 `(0, 1)`；渲染沿用门的 Path 投影，Boost 不改变通过截面的拍数。三种模型分别是蓝色带环晶体、粉色同心环、金色棱晶，均实时生成。每局使用独立 Run Seed；固定时间模式仍可重复生成相同画面。

## 规则与分数

以 60 Hz 仿真的输入路径，在第 303.99 拍过门后预留 150 ms，再用键盘轴移动到拾取范围。三种道具 × 三种难度共 9 局全部拾取成功，碰撞正常开启，均判定全部门并以 S 级结算。插值边界用例在相同输入下区分了拾取与错过；20、60、120、144 Hz 的驱动得到同一仿真结果。

| 难度 | 门数 | 未拾取 / Shield 无受击 | Resonance | Lumen |
| --- | ---: | ---: | ---: | ---: |
| Easy | 143 | 67701 | 68701 | 70201 |
| Normal | 144 | 107726 | 109326 | 112726 |
| Hard | 144 | 160426 | 162826 | 167926 |

独立用例验证：护盾挡下一次扣命，仍计漏门并中断 Combo；原有无敌期内的漏门不消耗护盾。Resonance 只在成功过门时扣次数，按实际过门分和 CLEAN 奖励加成，终止时丢弃余量。Lumen 在 Boost 下仍只给固定分，不改生命、Combo 或准确率。错过不会补发，退出重试不会继承效果。原四卷十二组分数基准未改，ELSEWHERE 的对照跑法明确断言错过道具。

## 人工试玩

请在 BREAK 过 Diamond 后，从中央略向上接取道具，再移回下一道 Iris 开口。优先确认默认画质和 Boost 下三种轮廓能否提前认出、移动端接取后转向是否舒适，以及拾取提示是否清楚。拾取后的护盾可用一次故意漏门验证；Resonance 可观察成功过门才减少的 HUD 余量。实际移动设备和真人手感未验，本轮未重跑完整真实时间音频和长时间 Soak。
