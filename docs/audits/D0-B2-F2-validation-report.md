## Spatial model

The Normal chart, with Main for the ELSEWHERE junction, builds one cached `ReferenceTrack` per Volume. At each 60 Hz sample, count the reference events through the preceding tick, damp the speed toward `24 + min(0.22 × count, 10)` using response `1.6`, and integrate. Interpolation maps authored Beat to world station `u`. Sightseeing uses `4200 + (u − 4200) / 3`, including the initial speed (8 rather than 24), with the same 1.45× Boost and five lives. The player's reference count advances by crossing reference stations, independent of misses, route gate count, score or random streams.

## Recovery

The monotonic Run Timeline drives fixed-step debt and establishes the Web Audio anchor with the existing 60 ms lead. Manual, background, BFCache and context pauses preserve the run offset. Foreground stalls keep accumulating time; the Runtime processes at most 12 fixed steps per RAF and defers drawing while behind. A verified input gap of about 150 ms or more opens a recovery window: its gates are processed once, marked neutral, and affect neither life, Shield, Resonance, Combo nor gate rewards. Very long gaps use the same bounded processing with a nonblocking status while catching up. Controlled tests cover 50, 100, 160, 250, 500 and 2300 ms. A native 160 ms main-thread block across the first ELSEWHERE gate confirms neutralization without a pause in Chromium and Firefox. Context loss freezes the run; a successful restore resumes the same state automatically. If restoration cannot complete, the runtime shows a graphics error instead of continuing blind.

The scheduler skips grid steps already in the past and resumes future steps on the original BPM grid. Tests cover a single 100, 160 or 250 ms delay and repeated delays, including protection against replaying an already-started step after resume. The native starvation test produced late-callback and missed-step diagnostics, then recovered without pausing or resetting the song. A suspended context is given one automatic attempt; if blocked, the run continues silently and a user gesture can restore audio at the current offset. This is separate from user-selected silent mode. Diagnostics include late callbacks, skipped steps, maximum delay, successful resumes and silent fallbacks.

Chrome real-time full songs had zero missing/duplicate steps and grid error under `1e-9` seconds: ELSEWHERE 1792 steps/141 gates (last crossing 209.489 s), DRIFT 896/40 (137.500 s), DESCENT 1600/158 (217.636 s), ORBIT 1280/91 (189.600 s). DRIFT Sightseeing separately played all 896 steps and passed 13/13 gates with five lives, at 140.000 s simulation time and about 140.054 s wall time from the pre-anchor sample. All five runs reached the original song-end Beat. The Standard runs kept the simulation within one 60 Hz step of the monotonic timeline during normal rendering.
