# A0 — Architecture & Correctness Audit Contract

以 `dev` 的实际 HEAD 为基准，审计 SoFarAway 的四个 Volume，先复现关键缺陷，再建立可复跑的规则、交互、渲染和音频基线。记录基准 SHA、环境、结论、未覆盖范围与 B0 风险。

## 范围

- **A0-A** 阅读运行入口、状态机、输入、计分、关卡与音频调度、路径、门、隧道、后处理、画质、程序化纹理和记录器。记录状态与依赖、生命周期、资源所有权、随机性及迁移边界。
- **A0-B** 核对 4 卷 × 3 难度的 BPM、时长、章节、门数、相邻门、种子、完成和失败统计。比较四种门的实际 Shader 开口与碰撞，验证桌面和触摸操作、设置、重开及音频时钟和静音。
- **A0-C** 在 Chromium 记录视口、DPR、画质、帧时间、draw calls、三角数、Three.js 资源计数、Render Target、Chunk 和重开变化。记录 WebGL 实现、驱动、系统、设备和测量区间。验证尺寸变更、运行时降级、上下文恢复和卸载。无法可靠验证的场景标记 `BLOCKED`，软件渲染仅作为该实现的基线。
- **A0-D** 为 P0 优先建立失败复现，随后做局部修复并复跑。P1 定位原因，低风险修复留在 A0，涉及引擎职责重划的工作移交 B0/C0。P2 记录证据。需要产品决定或大规模重构的 P0 作为迁移阻塞单列。

## 冻结边界

- 保持静态 HTTP 启动方式和现有运行时。修改限于可验证的关键缺陷、最小测试基础和审计文档。保留调试参数和四卷的内容、合成算法及渲染主体。Art Pass 2/3、视觉风格、编曲、关卡重新设计和发布另行处理。
- B0 采用 React Router Framework Mode + SSG、React、TypeScript Strict、Vite，游戏仍由独立 Three.js + WebGL2 + GLSL 引擎和 Web Audio 程序化音乐驱动。首轮迁移排除 R3F，部署候选为 Cloudflare Workers Static Assets 或 EdgeOne Pages。依赖安装、SSG 配置和部署变更归 B0。
- 游戏运行时的环境、几何、纹理和音乐均由程序生成。允许 Shader 源码、算法、种子、配置和文档截图。预烘焙场景贴图、预生成场景与预录音乐属于运行时禁用资产。
- 从 `dev` 审计，只在安全条件允许时提交并普通推送到 `dev`。`main`、分支合并、强推和发布均在本阶段范围之外。

## 验收

1. 提供可复跑命令和修复前后对照。普通碰撞参与通关测试，合成输入、固定时间和软件环境分别注明。
2. 覆盖四卷加载与核心流程、三难度规则、四类开口、失败与重试、时钟跳变、音量与静音以及关键渲染资源。离线信号验证和人工听感分开记录。
3. 报告每项已确认问题的文件、复现、预期和实际结果。用 `CONFIRMED` 标识有证据的遗留缺陷，`SUSPECTED` 标识待验证风险，`FIXED` 标识已复测的修复，`BLOCKED` 标识当前环境或测量能力限制。
4. 提供环境与真实性能样本、人工验收清单、模块保留及迁移建议，并作出 B0 准入判断。
5. 审查最终差异和工作区，只提交本阶段改动。
