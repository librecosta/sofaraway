# D0-A1 — Vol. I Gate & Gameplay

ELSEWHERE 使用三种固定玻璃门。本文以维护者冻结的任务规则为准，附件的图只提供几何结构参考。

| 门型 | 固定局部开口 | 自动对准 |
| --- | --- | --- |
| Iris | 原有八扇区之一，中央 Hub 半径 1.02，碰撞及开口沿用原判定 | 原有外围方向 |
| Square | 以原点为中心，`abs(x) < 1.35 && abs(y) < 1.35` | `(0, 0)` |
| Diamond | 以原点为中心，`abs(x) + abs(y) < 1.91` | `(0, 0)` |

方窗与菱窗的边界属于玻璃，内部由 Shader 丢弃片元。开口面积分别为 7.29 与约 7.30，保持固定尺寸、中心和方向。亮边和结构线在玻璃一侧，通道仍采用原有八边形外轮廓。

## 章节编排

每个章节从第一道门开始循环。I、S、D 分别表示 Iris、Square、Diamond。

| 章节 | 拍数范围 | 循环 |
| --- | --- | --- |
| INTRO | 0–16 | 无门 |
| A | 16–96 | I |
| B | 96–160 | I I I S |
| BUILD | 160–192 | I I I D |
| DROP | 192–288 | I I S I D |
| BREAK | 288–320 | I S I D I S |
| A2 | 320–384 | I I S I D |
| FINALE | 384–448 | I S I D I |

保留 128 BPM、448 拍和原 Chart 的 Beat、Sector、Section、种子及门间隔。先在完整谱面分配门型，再按旧规则过滤 Easy。Normal 和 Hard 各有 100 Iris、24 Square、20 Diamond，共 144 道。Easy 有 99 Iris、24 Square、20 Diamond，共 143 道。中央门不消耗额外随机数。Chart 和 Run Gate 携带相同门型，渲染、碰撞、CLEAN 和自动对准据此使用对应的几何或目标点。

## 边界与验收

- 禁止门体旋转、开口移动、偏移、变形、缩放和随难度改变。门型仅为 Iris、Square、Diamond。禁止 Split、第四种门型和新操作。
- 保留当前音乐、通道、相机、移动、Boost、生命、倍率、无敌期和渲染管线。DRIFT、DESCENT、ORBIT 延用各自的单一门型和既有结果。
- 以 60 Hz Simulation 的键盘轴输入和真实碰撞验证相邻门。每次通过后预留 150 ms，覆盖八方向、外围到中央、中央到外围、跨章节及快速连续门。383→384 拍保持 Iris → Iris。若实际不可达，先记录可复现的失败，再按维护者授权的范围做最小调整。
- 使用 Vitest 核对几何与谱面。真实 WebGL Shader 像素回读覆盖中心、边缘两侧、轴向顶点、斜边及 Iris 扇区。三难度使用碰撞开启的完整通关验证。交付检查包括 Strict、SSG、发布用例、相关兼容性、资源和同步回归。
