# D0-A2 — Vol. I Floating Pickups

ELSEWHERE 每局只出现一种浮空道具。试玩调整后，同一游戏实例的正常游玩按随机顺序每三次出场各发一种，提前退出且没到出场点不消耗本次抽取。道具在 BREAK 的 306.66 拍通过玩家截面，局部位置固定为 `(0, 1.0)`，拾取半径固定为 `0.7`。使用 60 Hz 仿真中跨过该拍时的插值坐标结算一次。错过即消失，无碰撞伤害或扣分，不计入门数和准确率。

| 道具 | 效果 |
| --- | --- |
| Prism Shield | 抵消下一次原本扣命的撞门，随后失效。该门仍计作未通过，Combo 中断，按原规则开始受击无敌期。已受无敌期保护的漏门不会消耗护盾。 |
| Resonance | 接下来的 8 次成功过门额外获得该门分数的 25%，包含实际获得的 CLEAN 奖励。漏门不扣次数，路程和其他奖励不参与加成，未使用次数在结算时失效。 |
| Lumen | 立即奖励 Easy 2500、Normal 5000、Hard 7500 分。固定分值不再叠乘难度倍率、Boost 或 Resonance；不影响生命、Combo 或准确率。 |

新一局生成独立的 Run Seed，暂停、恢复不重抽，退出和重试清除效果。道具使用独立的随机流，不改变原有 Volume／难度种子或未来其他随机流的结果。测试可向 Runtime 传入种子；固定时间截图默认使用固定种子。

Simulation 持有道具与计分状态，Graphics 仅根据状态在 Path 上渲染程序化模型，React HUD 显示短时拾取反馈及护盾或 Resonance 余量；接近道具时不加名称提示。保留现有 128 BPM、三种门型、时间轴、过门判定、控制、音乐、场景和其他三个 Volume。D0-A2 不增加三岔路、第四种道具、新操作或离线资源。项目许可继续为 BSD-3-Clause。

验收包括三种道具在三种难度中的正常碰撞通关、固定步判定、随机性隔离、道具计分、暂停和重试、GPU 资源释放，以及现有四卷谱面、分数、碰撞、音频和生产构建回归。通过检查后普通推送 `origin/dev` 并核对远程 SHA；不修改 `main`，不部署。
