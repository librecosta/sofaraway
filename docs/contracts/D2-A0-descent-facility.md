# DESCENT laser security facility

The [CONTROL score](../../app/game/core/descent-score.ts) defines 136 BPM, 384 beats and seven chapter boundaries. The [facility plan](../../app/game/core/descent-facility.ts) maps these boundaries through the shared ReferenceTrack. ORDER and LOCK use CONTROL, FLIGHT uses TRANSIT, PRESSURE uses THE WELL, HOLD uses CORE, and LOCKDOWN and BREACH use their namesake spaces. The camera, gate frames and streamed architecture sample the same Path. Sightseeing fits the same progression to its shorter route. Boost changes when the player reaches each structure.

The [laser gate contract](../../app/game/core/descent-gates.ts) defines the aperture and beam dimensions used by swept collision and the [Gaussian material](../../app/game/graphics/laser-gates.client.ts). Matrix clears one perimeter cell and energizes a 3×3 lattice in each of the other eight cells, including the central cell. Slice opens a horizontal or vertical band. Weave opens a diagonal band with mirrored slopes. Collision uses the beam bodies, so the gaps and optical halo are traversable. Color progresses along the authored chapter stations. The light waveform affects appearance only.

DESCENT stages gates 450 units ahead in both modes so the shared preview queue covers the 420-unit camera range. The field and metal frame draw without an entry fade. All laser beams contribute at every visible distance. Pixel coverage filters fine beams and preserves the aperture contour at subpixel widths. Each gate uses one field draw and one draw for the metal frame and emitter sockets, which share geometry.

The [architectural composition](../../app/game/graphics/descent-architecture.ts) separates the inner octagonal flight conduit, service frames and the outer facility envelope. CONTROL uses short inspection bays. TRANSIT suspends raised freight ways beyond the flight rails. THE WELL uses repeating shaft decks, intermediate catwalks and continuous load-bearing piers around the vertical drop. CORE widens the chamber and spaces concentric stator rings through the HOLD passage. LOCKDOWN nests close-set security bulkheads. BREACH progressively opens the roof while the remaining side supports carry the lower service structure.

The construction follows the same path and zone stations as the gates. Section dimensions blend through the boundaries, and the shared tunnel streamer owns the geometry of each chunk. Mirrored frames keep the flight envelope and openings clear. Chunk batches share one structural material, one steady cold-white work light material and one security material. Only security lights use the CONTROL fixture response. The chapter laser palette and collision stay independent of both lighting layers.

The [D2-A1 choreography](../../app/game/core/descent-chart.ts) uses four-bar movements placed on CONTROL kick, snare and fill onsets. ORDER introduces 8 gates after the first six beats. LOCK uses 28, FLIGHT 42, PRESSURE 40, HOLD 5, LOCKDOWN 40 and BREACH 11. LOCKDOWN places 40 gates in 64 beats, with the shortest repeated intervals. Matrix dominates ORDER and LOCK, Slice drives FLIGHT, and Weave introduces diagonal movement in PRESSURE and returns in LOCKDOWN. The last gate is at beat 372. Easy, Normal and Hard share the 174-gate chart. Sightseeing samples 58 gates. The Local Records key `descent-laser-choreography` keeps D2-A1 results separate, including from D2-A0's `descent-laser-security` results.

Use `/debug/#descent` for seven real scene views and `/debug/#gates-descent` for all gate states. The ordinary gameplay route is `/?vol=descent`.
