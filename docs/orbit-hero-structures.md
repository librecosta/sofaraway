# Hero asteroid geological structures

The E2 hero builder replaces radial sphere displacement with five fixed constructive solids. Angular lofts and bounded block displacement form the mother rock; finite cutting volumes excavate faults, undercuts and crater walls. The shared E1 `OrbitRockSurface` still supplies lithology, grain and filtered micro detail. Cutter ownership supplies the existing fresh/fault/peel/weather attributes, with subdued fault shading because the void now exists in geometry.

- **Fractured Monolith:** tapered open fault, unequal shear faces, corner loss, and an attached skin plate with a real recess behind it.
- **Twin-Lobe Mass:** one continuous unequal-lobe solid with an oblique narrow neck, neck excavation and a chipped lower lobe.
- **Stratified Cliff:** three thick, offset slabs connected by a rear spine; recessed, irregular interfaces leave actual overhangs.
- **Impact Scar:** excavated bowl with distinct floor/wall slopes, incomplete raised rim, secondary pit and missing rim blocks.
- **Elongated Shard:** angular asymmetric thin/thick loft, long structural incision, undercut and finite edge cuts.

Cell-constrained dual extraction uses regularized plane fitting and consistent shared-face connectivity. Geometry is indexed, closed and connected. The finite family/LOD set is tested for edge incidence and winding, nondegenerate triangles, normals, deterministic attributes, actual ray-visible recesses and the original unit-sphere safety envelope. No body descriptor, world position, route clearance, scoring, soundtrack, chart, light cue, nebula or planet changes are involved.

Production retains fixed High/Auto geometry and fixed medium geometry on Low. Every attached structure is part of its mother's mesh from initial visibility. Immutable CPU arrays are cached for the finite family/LOD set; each world receives independently owned geometry buffers and GPU resources. No extraction runs during frame updates. Shared-face arc subdivision resolves pinched dual edges. Disconnected, unresolved cell-scale remnants are removed within an explicit size budget; substantial detached masses fail generation instead of being hidden. High family triangle counts are 8,496 / 7,192 / 8,344 / 8,988 / 5,512, versus 6,016 / 6,016 / 6,016 / 6,016 / 5,648 before E2.

## Inspection and measurement

The browser harness exposes `inspectOrbitSurfaces(quality, view, neutral)` using actual production meshes. `front`, `side`, `back`, `oblique`, `backlit`, `strong` and `flight` views are supported. Neutral mode temporarily substitutes one plain Standard material; it does not build substitute geometry. The player-camera approach harness also accepts an optional difficulty and checks fixed geometry/material identities through cruise and Boost.

Fixed-seed before/after evidence against `fda1b33` is kept in ignored `scratch/orbit-m1/hero-structures/`. Chrome 157.0.8103.79, AMD Radeon D3D11, 960x540, DPR 1; three hero-containing production stations (beats 8, 42 and 140), three quality tiers, two interleaved repetitions, 180 measured frames per sample. Mean station GPU P95 (ms): Low 1.47 -> 1.86, Auto 2.17 -> 2.26, High 2.34 -> 2.27. Low pays about 0.39 ms for the additional geometry in these samples; Auto/High changes are small relative to run variation and are not evidence of a rendering speedup. Mean GPU P95 stays below 3 ms in each quality tier. Mean frame-interval P95 (ms) was Low 4.25 -> 4.28, Auto 4.27 -> 4.30 and High 4.27 -> 4.28. Draw calls, programs, geometry and texture counts are unchanged. Hero-containing samples add submitted triangles without new draw calls; the six-station pre-final survey also confirmed unchanged later non-hero scenes.

Single cold-world observations measured 953 -> 1,595 ms in a fresh page, including shared surface initialization. Cached repeat construction measured 55-87 ms versus baseline 226-337 ms. This is an initialization tradeoff, not per-frame cutting or a distance-driven model change. Further hand-shaped asymmetry or exact geological simulation is outside this implementation; the deliberately quiet shear faces retain the common E1 material rather than receiving extra decorative crack layers.

Validation: Node 24 typecheck, 352 core tests, the complete 171-case browser suite and all 7 performance cases passed. The latter includes neutral and production-material views of all five families, fixed geometry/material identities during Normal/Impossible cruise and Boost, all branch layouts, seven-scene quality/resource checks, context restoration, the real full STARWAKE/Encore ending, and the other three volumes. Representative menu captures, before/after views and continuous flight video are retained in the ignored evidence directory above.
